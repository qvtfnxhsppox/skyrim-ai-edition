## Overview

Skyrim AI Edition overhauls NPC behavior trees and dialogue systems using local LLM inference, giving every named character contextual memory, emergent conversation, and reactive storylines shaped by your choices.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Skyrim AI Edition** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Contextual Memory** | NPCs recall past interactions and reference them in future dialogue |
| **Dynamic Quests** | AI generates contextual errands and rumors based on world state |
| **Combat Intelligence** | Enhanced follower tactics and enemy flanking powered by behavior trees |
| **Voice Synthesis** | Optional TTS integration matches AI dialogue to character voice profiles |
